# GS Tools — 本地技术资讯聚合器

> 一款 Windows 桌面应用，自动聚合 GitHub、Gitee、博客园、微信公众号等技术资讯，打造你的个人技术阅读器。

## 📥 下载安装

前往 [Releases](https://github.com/TwoToken/GS_Tools/releases) 页面下载最新版本。

| 版本 | 说明 |
|------|------|
| **Setup.exe (x64)** | 64 位安装版（推荐，适合大多数电脑） |
| **Setup.exe (x86)** | 32 位安装版（适合老电脑） |

双击 Setup.exe 安装，启动后会自动开始工作。应用支持自动更新，发布新版本时会弹窗提醒。

## ✨ 功能一览

### 🔍 多源资讯聚合

从四大技术平台自动采集与你关注领域相关的内容：

- **GitHub** — 热门仓库、Trending 日榜/周榜/月榜、搜索结果
- **Gitee** — 推荐项目、探索页、搜索结果
- **博客园** — 首页推荐、10 个技术分类页、精华区、RSS 订阅
- **微信公众号** — 搜狗搜索 + 合集/目录订阅，自动追踪公众号更新

### 🏷️ 智能关键字

- 自定义关键字，精准筛选感兴趣的技术内容
- **智能推荐**：根据你的阅读偏好自动生成关键字建议（基于词频 + 阅读时长 + 收藏偏好）
- **三级策略**：词云权重词 → 自定义关键字 → 内置默认词，逐步扩展覆盖面

### 📖 内嵌阅读器

- 点击文章直接在应用内打开原文网页，带加载进度条
- **内置翻译**：Google Translate + Microsoft Translator 双引擎，一键翻译整篇文章
- **阅读计时**：自动记录每篇文章的阅读时长（离开页面自动暂停）
- **收藏功能**：标记收藏文章，随时回顾

### 📊 数据统计面板

可视化展示你的阅读习惯：

- 总文章数、已读/未读数量、累计阅读时长
- 来源分布饼图（GitHub / Gitee / 博客园 / 微信各占比多少）
- 30 天阅读趋势图
- 7 天爬取活动记录

### ☁️ 词云系统

- **文章词云**：阅读超过 30 秒后自动生成，提取文章关键词
- **全局词云**：综合所有已读文章，展示你最关注的技术方向（气泡布局）
- 可配置词云最大词数（10 ~ 500）

### 📤 文章导出

支持多种格式导出：

- **Markdown** — 含图片下载到本地，适合二次编辑
- **PDF** — 保留原始排版，适合存档
- **DOC** — Word 格式，适合分享

支持单篇、按订阅、按来源批量导出。

### 📌 微信公众号订阅

- 粘贴微信文章链接，自动识别公众号并创建订阅
- 支持**合集订阅**和**文章目录订阅**
- 定时自动刷新订阅内容
- 在阅读器底部一键"添加订阅"

### 🎨 个性化设置

- **主题模式**：亮色 / 暗色 / 跟随系统
- **界面语言**：中文 / 英文
- **翻译设置**：选择翻译引擎和目标语言（支持 12 种语言）
- **爬取间隔**：自定义爬取频率（默认 30 分钟）
- **代理配置**：支持 HTTP 代理
- **配置备份/恢复**：一键导出和恢复所有设置

## 🚀 快速上手

### 1. 安装并启动

下载 Setup.exe 安装后双击桌面图标启动。首次启动会自动：

- 创建默认配置（关键字：前端、TypeScript、Vue、React、Node.js 等）
- 开始第一轮爬取（约 1~3 分钟）
- 在左侧分类树中显示爬取结果

### 2. 浏览资讯

```
┌──────────────────────────────────────────────────┐
│  [搜索框]                              [设置⚙️]  │
│                                                   │
│  📂 全部 (128)                                    │
│  ├── 📂 GitHub (45)                               │
│  │   ├── 📅 日榜 (15)                             │
│  │   ├── 📅 周榜 (15)                             │
│  │   └── 📅 月榜 (15)                             │
│  ├── 📂 Gitee (30)                                │
│  ├── 📂 博客园 (33)                               │
│  └── 📂 微信公众号 (20)                            │
│                                                   │
│  [全部] [未读] [已读] [⭐收藏]                     │
│                                                   │
│  ┌ 文章列表 ──────────┐  ┌ 阅读器 ─────────────┐ │
│  │ 📄 文章标题 1      │  │                     │ │
│  │ 📄 文章标题 2      │  │  点击左侧文章       │ │
│  │ 📄 文章标题 3      │  │  在此处阅读原文     │ │
│  │ ...                │  │                     │ │
│  └────────────────────┘  └─────────────────────┘ │
└──────────────────────────────────────────────────┘
```

- 点击左侧**分类树**切换来源
- 点击**文章列表**中的文章，右侧阅读器打开原文
- 使用**统计栏**切换 全部/未读/已读/收藏 视图

### 3. 自定义关键字

点击右上角 **⚙️ 设置** → **关键字管理**：

- 添加你感兴趣的技术关键字（如 `Rust`、`机器学习`、`K8s`）
- 删除不需要的默认关键字
- 系统会根据你的阅读习惯自动推荐关键字

### 4. 翻译文章

在阅读器中打开英文文章后，点击顶部工具栏的 **🌐 翻译** 按钮：

- 自动翻译整篇文章
- 点击翻译栏切换"显示原文"/"显示译文"
- 在设置中选择翻译引擎（Google / Microsoft）和目标语言

### 5. 订阅微信公众号

两种方式：

1. **粘贴链接**：复制微信文章 URL，粘贴到搜索框，自动识别并创建订阅
2. **阅读时订阅**：在阅读器中打开微信文章，点击底部的绿色"添加订阅"按钮

### 6. 导出数据

设置页面 → **文章导出** → 选择格式和范围：

- 单篇导出：右键文章 → 导出
- 批量导出：按来源或订阅批量导出为 Markdown / PDF / DOC

## ❓ 常见问题

### 为什么某些来源没有爬取到数据？

- 检查网络连接是否正常
- 部分平台有访问频率限制，应用内置了智能限流和熔断机制
- 微信公众号爬取依赖搜狗搜索，可能被临时限制
- 可在设置中调整爬取间隔

### 翻译功能不工作？

- 检查网络连接
- Google Translate 需要能访问 `translate.googleapis.com`
- 可在设置中切换翻译引擎（Google ↔ Microsoft）
- 一个引擎不可用时会自动回退到另一个

### 如何备份/恢复数据？

- **配置备份**：设置 → 配置管理 → 导出配置
- **数据备份**：手动复制 `%APPDATA%\GS Tools News Client\` 目录下的 `news.db` 文件
- **恢复**：将备份文件复制回原目录

### 应用占用内存较大？

- 应用使用内存数据库（sql.js）提升性能，数据定期落盘
- 文章数量过多时可导出后清理旧文章
- 应用内置内存监控，超过阈值会发出警告

### 如何使用代理？

设置 → 代理配置 → 输入代理地址（如 `http://127.0.0.1:7890`），爬取和翻译请求都会走代理。
